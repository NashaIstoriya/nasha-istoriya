НАША ИСТОРИЯ — прототип 0.1

ФАЙЛЫ
- index.html — игра для телефона и компьютера.
- database.rules.json — правила Realtime Database для тестового прототипа.

КАК ЗАПУСТИТЬ
1. В Firebase Console открой Authentication → Sign-in method. Anonymous должен быть Enabled.
2. Открой Realtime Database → Rules.
3. Замени правила на содержимое database.rules.json и нажми Publish.
4. Размести index.html на HTTPS-хостинге (например, Firebase Hosting) или открой через локальный сервер разработки.
   Не открывай как file:// — браузер может блокировать модульные импорты.
5. Открой опубликованную страницу на своём телефоне, создай комнату.
6. Отправь Ире ссылку на ту же страницу и код комнаты. На её телефоне: ввести имя → Войти по коду.

ВАЖНО О БЕЗОПАСНОСТИ
Это ранний прототип. Правила разрешают любому анонимно авторизованному пользователю читать и менять данные комнат, если он знает/угадает код. Код комнаты случайный, но это не полноценная защита. Не используй эти правила для личных данных или публичного релиза. Перед публикацией нужно добавить проверку членства в комнате, ограничения на запись только своего player UID, очистку комнат и защиту от спама.

Firebase web config (включая apiKey) обычно находится в клиентском приложении и сам по себе не является секретом. Никогда не публикуй service account JSON, приватные ключи или пароли.
